# calc.dev
Não tenho muitos projetos no GitHub, então para eu poder um inicio igual os demais, decidi fazer os projetos básicos para ir praticando. Dessa forma, desenvolvi uma calculadora para iniciantes em programação, criada com HTML, CSS e JavaScript puros.

## Estrutura
o arquivo se divide em 3 elementos
- index.ghtml
- main.js
- style.css

Eles se divide dessa forma para que possamos organizar com eficiência o código. Também serve para podermos alterar alguma coisa no nosso código, assim podemos colocar mais alguma operação no arquivo do Javascript, como potência, raiz quadrada e etc, ou também para que a gente possa retirar.

## Recursos
A idéia é fazer com que ela opere com: 
- Operações básicas, porcentagem e números decimais
- Suporte ao teclado
- Histórico dos cinco cálculos mais recentes
- Painel didático que mostra a expressão em JavaScript
- Layout responsivo e acessível

## Como executar

Abra o arquivo \`index.html\` em qualquer navegador moderno. Não é necessário instalar dependências.


## Estágio
De forma a progredir na nossa calculadora, devemos inserir mais elementos operacionais para que ela se torne também uma calculadora cientifica, com,
- Raiz Quadrada
- Potencia
- seno, cosseno e tangente
- logaritmo (log) e logaritmo natural (ln)
